# 兵种美术提示词体系（星际反抗军风格）

> 核心原则：**先锁定整款游戏的画风（风格锚点），再往里面填每个兵种的"人设"（主体）。**
> 风格锚点一经确认，生成每张图时原样复制，不允许修改；每个兵种只改【主体】段。

## 1. 风格锚点（唯一权威版本，复制粘贴用）

```
星际探索与星际战争题材的科幻游戏单位美术，星际反抗军主题。
半写实厚涂风格，明快通透但不卡通。
主色调：亮钢蓝、银白、暖橙、黄铜、深空蓝紫。
材质：光洁合金装甲、战术织物、发光能量晶体、磁轨金属。
装饰：简洁徽章、条纹涂装、利落的战损划痕。
光影：明亮通透，左上45度主光，冷蓝环境光与暖橙点缀光，高对比不压抑。
构图：全身像，主体居中，轮廓清晰。
禁止：文字、水印、logo、血腥、残肢、恐怖元素、压抑暗黑。
```

可选强化：全员左肩佩戴同款橙色条纹肩章（统一标识，增强"反抗军"辨识度）。

## 2. 公共段（9 张图全部一致）

```
【姿态】标准战斗待机，全身像，居中构图，四周留10%安全边距
【视角】四分之三侧视
【光线】左上45度明亮主光，冷蓝环境光+暖橙点缀光
【产出】竖版2:3，纯深灰色背景便于抠图，无文字无水印
```

例外：**减速塔、矿工**等设施/机械单位，【视角】改为 **俯视45度**（突出占地轮廓，方便游戏内摆放对齐）。

## 4. 视角与光线速查（非美工友好版）

### 视角 = 相机放在哪看
- **正面平视**：适合头像、卡片、按钮图标，AI 翻车率最低。
- **四分之三侧视**：本游戏主力视角，战斗场景单位立体感最好。
- **俯视45度**：塔、设施、机器人，突出占地轮廓。
- **三视图**：正面+背面+侧面并排，用于角色设定/换装参考。

### 光线 = 只记三个词
- **主光**：决定明暗方向，默认"左上45度"最安全。
- **轮廓光**：从背后打，把角色边缘勾亮，跟背景分开。
- **氛围**：整体明暗冷暖。本游戏固定"明亮通透 + 蓝橙对比"。

## 5. 多角度与贴图写法

- 多方向图：
  `【视角】四方向：正面、背面、左、右四个方向，统一光影与配色，透明底，适合做游戏精灵图`
- 三视图：
  `【视角】三视图：正面、背面、侧面三个等大全身像并排，统一光影与配色`
- 单帧贴图：
  `【产出】游戏内单位贴图，正面待机帧，透明底，脚底踩在画面底部边缘，便于对齐地面`

## 6. 生产流程

1. **出风格样张**：用锚点 + 盾卫兵主体出 2 张，确认画风。
2. **锁定锚点**：确认后锚点一个字都不许改。
3. **9 兵种各出一张标准立绘**：只改【主体】【姿态】两段。
4. **重点单位出多角度**：主角/高频单位才值得做三视图或多方向。
5. **拆贴图入库**：统一尺寸、透明底、按命名规范存放 `assets/Art/units/`。
