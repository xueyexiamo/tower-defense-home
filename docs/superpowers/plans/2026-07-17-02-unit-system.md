# 兵种体系实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在核心战斗 Demo 基础上，添加 10 种不同兵种类型（覆盖 4 大分类），每种兵种有独特的属性、攻击方式和视觉表现。

**Architecture:** 新增 `UnitData.ts` 集中管理兵种配置。`UnitBehavior` 实现策略模式。`BuildPanel` 提供建造界面。

**Tech Stack:** Cocos Creator 3.x, TypeScript

## Global Constraints

- 兵种配置文件 `UnitData.ts` 为唯一数据来源
- 每个兵种类型对应唯一 ID
- 行为差异通过 `IUnitBehavior` 接口实现
- 外观用颜色和几何图形区分

---

## Task 1: 兵种数据配置

**Files:** Create `assets/Scripts/Data/UnitData.ts`

**Produces:** 10 种兵种数据定义（ID、名称、分类、属性、外观参数）

兵种：盾卫兵(肉盾)、枪兵(对空)、狂战士(高输出)、弓箭手(单体)、弩手(穿透)、法师(AOE)、治疗兵、减速塔、矿工(产出能量点)、无畏战甲(终极)

`git add assets/Scripts/Data/UnitData.ts && git commit -m "feat: 兵种数据配置 - 10种兵种类型定义"`
